# SumatraPDF-Extras
Different to [SumatraPDF-Plus](https://github.com/GitHubRulesOK/SumatraPDF-Plus) (generally using External Viewers or internal CMD) these are Enhanced Web.js functions generally inside SumatraPDF WV2 (although they too may be loaded via internal or external CMD)

These have been tested in slow Atom 2GB NB x32 (using Windows 7 SP1 + WebView2) and also proven in Windows 10x64 sandbox. They may not all work in SumatraPDF NG but should work in Org. 3.7.##### after time of testing (currently 3.7.24566)

First simple test example is an [Image Book Maker](https://github.com/GitHubRulesOK/SumatraPDF-Extras/blob/main/ImageBook/README.md)  (Modified especially from [lometogo/flip-book](https://github.com/lometogo/flip-book)) Adapted so you can use in the WebView to build CBZ comics or a Photo Album or Images of documents.
